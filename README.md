# Deployment

## From Codespace

1. Go to Code > Codespaces > Create a codespace on main
2. Go to the Terminal tab at the bottom and run 
```python
python -m http.server 5000
```
3. Go to the Ports tab and click the the link under Forwarded Address

## From downloads
1. Go to Code > Local > Download ZIP > you can handle it from there
