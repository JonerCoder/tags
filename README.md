# Deployment

## From Codespace

1. Go to Code > Codespaces > Create a codespace on main
2. Go to the Terminal tab at the bottom and run 
```python
python -m http.server 5000
```
3. Go to the Ports tab and click the the link under Forwarded Address

## From downloads
1. Go to Code > Local > Download ZIP > you can handle it from there

## Terminal demo

Open [`pages/terminal.html`](pages/terminal.html). Run `ls` to list all desktop apps or `open <app name>` to launch one in the terminal window (for example, `open calculator`).

The terminal is simulated and does not execute operating-system commands.
